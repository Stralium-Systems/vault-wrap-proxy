# Changelog

## 1.0.0

- Initial release of the self-hosted Vault Wrap Proxy interface and API.
- One-time secret sharing with configurable expiry and request size limits.
- English by default, with French and Spanish selected through deployment configuration.
- Stateless proxy with Kubernetes authentication, coordinated reauthentication and authenticated readiness.
- Helm chart, optional Vault permission examples, and a disposable Docker Compose demonstration.
- Tests for real Vault sharing, browser behavior, localization, input safety and container deployment.
